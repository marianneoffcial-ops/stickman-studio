Stickman Explainer Engine

A step-by-step production assistant for researched stickman explainer videos. It creates timed narration, scene prompts, voiceover, an animated MP4 and a matching 16:9 thumbnail. Stickman movement is procedural; optional painterly backgrounds use Cloudflare Workers AI when configured. This hybrid renderer is not a full neural video-generation model.
